# Lesson format — HTML template and practice formats

Reference for Scenario B lessons generated by `/start-learn`. Each lesson is a self-contained HTML file in `lessons/`.

## Fixed structure (every lesson)

```
1. Lesson title + objective
2. Explanation — the agent teaches, with source citations
3. Adaptive practice — format chosen to suit the topic
4. Recommended primary source + link to the next lesson
```

Always use this structure. The practice section's format varies.

## Adaptive practice formats

### A-B-C-D (default)

For languages, theory, and terminology. Use standard multiple-choice questions. Every answer option must have the same number of characters, so visual length gives no clue to the correct answer.

### SVG diagram

For spatial topics: chessboards, flowcharts, anatomy, circuits. An inline SVG diagram precedes the question. The question asks the user to identify something, place something, or reason about the diagram.

### Code editor

For programming. Use a monospace `<textarea>` and a "Check" button with inline JS that compares the output. Include the verification code in the HTML file, with no external dependencies.

### Sequence display

For procedures: Rubik's Cube sequences, yoga moves, step-by-step algorithms. Display the sequence and ask the user to complete or correct it.

## HTML template

```html
<!DOCTYPE html>
<html lang="<language>">
<head>
  <meta charset="UTF-8">
  <title><N>. <Lesson title></title>
  <style>
    /* Tufte style: serif font, limited width, generous margins */
    body { max-width: 640px; margin: 4rem auto; font-family: Georgia, serif;
           line-height: 1.7; color: #222; padding: 0 1.5rem; }
    h1 { font-size: 1.4rem; } h2 { font-size: 1.1rem; margin-top: 2rem; }
    .objective { color: #555; font-style: italic; margin-bottom: 2rem; }
    .practice { background: #f8f8f8; border-left: 3px solid #ccc;
                padding: 1rem 1.5rem; margin: 2rem 0; }
    .feedback { margin-top: 0.5rem; font-weight: bold; }
    .nav { margin-top: 3rem; border-top: 1px solid #eee; padding-top: 1rem;
           font-size: 0.9rem; }
    cite { font-size: 0.85rem; color: #666; }
  </style>
</head>
<body>
  <h1>Lesson <N> — <Title></h1>
  <p class="objective">Objective: <one sentence></p>

  <h2>Explanation</h2>
  <p><!-- teaching content, with inline citations --></p>
  <cite>Source: <link to an authoritative source></cite>

  <h2>Practice</h2>
  <div class="practice">
    <!-- adaptive practice section: A-B-C-D / SVG / code editor / sequence -->
  </div>

  <div class="nav">
    <strong>Primary source:</strong> <a href="...">...</a><br>
    <!-- if a next lesson exists: -->
    <a href="000N-next.html">→ Lesson N+1</a>
  </div>
</body>
</html>
```

## File names and numbering

File: `lessons/000N-kebab-slug.html`, where N is the lesson number in `CURRICULUM.md`, padded with zeros to four digits. Derive the slug from the title.

## Rules

- **No external dependencies** — no CDNs or remote scripts. The file must open offline.
- **Printable** — Tufte style (narrow columns, serif type) is designed for printing.
- **Equal-length answer options** — for A-B-C-D, use the same character count for every option to avoid visual clues.
- **Immediate feedback** — inline JS shows correct/incorrect feedback on click, without reloading the page.
